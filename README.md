# Roidoya Character Chat Platform

Roidoya Character Chat Platform (RCCP) is an early-stage character-chat platform currently under development.

It is designed to support character-chat services, including systems commonly referred to as AI characters or AI companions.

Development is currently focused on implementing the platform described by the following documents:

- [RCCP Concept](docs/concept/README.md)
- [RCCP Architecture and Technical Disclosure](docs/publications/rccp-architecture-and-technical-disclosure.md)

The current implementation does not yet implement the platform described in these documents. It should be regarded as earlier implementation work rather than as the current RCCP specification.

## Public Edition #7 highlights

Public Edition #7 describes selecting the contract versions included in a build and adding capabilities for environments through developer-provided extensions in a chosen programming language.

The build embodiments resolve exact contracts from a pinned catalog, exclude unselected version-specific implementations, and verify compiler inputs, artifacts, and registrations. Extension embodiments use compatible packages, remote services, or message workers while preserving transaction, durability, identity, and authority boundaries. Artifact integrity, conformance evidence, operator approval, and official support remain separate.

See Sections 105–113, Figures 23–24, Reference Embodiments R16–R19, Combinations BX–CC, and Technical Propositions TP-61–TP-68 in the [Technical Disclosure](docs/publications/rccp-architecture-and-technical-disclosure.md). Fixed Markdown, PDF, and checksums are available in the [Public Edition #7 release](https://github.com/AkihiroFujimotoChocolate/roidoya-character-chat-platform/releases/tag/rccp-technical-disclosure-edition-007).
